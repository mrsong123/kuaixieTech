# 商品图片与私有附件

商品发布使用本人上传的 JPEG/PNG，单张不超过 10MB，完整解码前限制边长 12000、总像素 2500 万。此检查不等于内容审核或恶意文件扫描。身份证照、保险证明等私有文件不能作为商品图片发布。

发布保存规范路径 `/public/media/{uuid}`。商品事务按 UUID 顺序锁定附件，校验所有者、用途、类型、大小和哈希记录，并建立 `t_upload_bindings`。创建订单保留图片绑定，防止商品后续编辑使订单凭据失去引用。外部历史 HTTPS 图片仍限配置的媒体域名。

公开图片仅在商品可公开销售、库存充足、卖家有效且店铺未被停用时返回，响应禁止缓存。商品下架或售罄后，订单参与方仍可通过 `/me/uploads/{id}/content` 鉴权读取；各端使用认证下载后的临时地址，不把 JWT 放入图片 URL。

删除未使用附件先提交 `deleting` 状态和删除记录，再向对象存储发出幂等 DELETE；只有确认后记 `deleted`。引用、消费、订单或行程归属存在时拒绝删除。未知结果保留 deleting，可查询记录并显式重试，不能当作成功。

新对象引用记录配置版本。正版本读取保存的 LIVE 密文配置快照；旧引用仅查旧 LIVE 配置，不跟随当前 SANDBOX 或新供应商。旧配置未曾版本化的历史对象仍依赖原配置保留，轮换前必须迁移和核验。

迁移 010 仅追加绑定和删除记录表，已汇入最终部署 SQL。开发期间没有执行迁移、连接真实库或调用真实对象存储。数据库并发、存储权限与恢复行为仍待部署环境验证。
